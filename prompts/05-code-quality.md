# 高质量代码提示词

请根据需求和设计实现或审查代码，优先保证清晰、可维护、可测试。

## 执行流程

1. 确认关联需求和设计文档。
2. 阅读现有代码结构和测试结构。
3. 明确输入、处理、输出。
4. 小步实现功能。
5. 补充或更新测试。
6. 运行格式化、类型检查、测试或构建命令。
7. 输出变更说明和剩余风险。

## 代码原则

- 单一职责。
- 命名语义化。
- 避免无依据的抽象。
- 错误处理统一。
- 公共行为有测试。
- 注释解释“为什么”，不是复述“做什么”。
- 配置和密钥分离，真实密钥不进入仓库。
