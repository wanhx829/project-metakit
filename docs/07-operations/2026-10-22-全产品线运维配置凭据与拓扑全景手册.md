## 3. 核心目录与持久化规划

- **控制台主目录**：`/deployment/deploy/`
  - 主执行文件：`/deployment/deploy/syncplant-auto-deployment`
  - 数据存储：`/deployment/deploy/deployment_data.db` (SQLite 3)
  - 运行时配置：`/deployment/deploy/conf/app.ini` 或 `application.yml`
- **基础配置注入文件**：`/root/replace.json`（存放云端初次包注入的全部中间件初始账号、密码、IP、网络网段配置）
- **模块与介质缓存目录**：`/deployment/soft/` 与 `/deployment/packages/`
- **微服务存储挂载点**：
  - MySQL 数据盘：`/deployment/data/mysql/`
  - Redis 数据盘：`/deployment/data/redis/`
  - MinIO 数据盘：`/deployment/data/minio/`
