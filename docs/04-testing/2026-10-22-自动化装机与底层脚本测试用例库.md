## 2. 详细测试用例契约

### TC-BOOT-001: 目标 IP 连通性门禁拦截校验
- **前置条件**：已知局域网在线 IP（如网关或控制台自身）。
- **操作步骤**：
  1. 向装机流程输入该在线 IP；
  2. 执行 preflight ICMP Ping 检查。
- **预期结果**：Ping 返回有响应（丢包率 < 100%），装机流程**强制阻断**，输出“IP 处于在线状态，禁止执行装机，避免冲突”告警。
- **自动化验证命令**：
  ```bash
  ping -c 3 -W 1 <ip> && echo "BLOCK" || echo "PASS"
  ```

### TC-BOOT-004: 装机完成 SSH 22 端口连通性验收
- **前置条件**：PXE 装机流程状态显示完成。
- **操作步骤**：
  1. 向目标机 IP:22 发起 TCP 连接；
  2. 携带预置公钥或密码执行 `echo "READY"`。
- **预期结果**：连接在 30 秒内建立，成功返回退出码 0 与预定字符串。
- **自动化验证命令**：
  ```bash
  ssh -o StrictHostKeyChecking=no -o ConnectTimeout=5 root@<target_ip> "echo OK"
  ```

### TC-BASE-004: K8s 节点就绪与 Cilium eBPF 运行状态测试
- **前置条件**：宿主机 `install.sh` / `start.sh` 执行完毕。
- **操作步骤**：
  1. 登录目标宿主机；
  2. 执行 `kubectl get nodes` 与 `kubectl get pods -n kube-system`。
- **预期结果**：
  - 宿主机 Node 状态为 `Ready`；
  - `cilium` Pod 为 `1/1 Running`；
  - 无 Evicted、CrashLoopBackOff 或 Error 状态 Pod。
- **自动化验证命令**：
  ```bash
  ssh root@<target_ip> "kubectl get nodes --no-headers | awk '{print \$2}'"
  # 必须等于 "Ready"
  ```
