# Test Process

## 流程概览

1. 需求评审。
2. 测试方案编写。
3. 测试点拆解。
4. 测试用例编写。
5. 测试用例评审。
6. 测试执行。
7. 缺陷提交和回归。
8. 测试报告输出。
9. 验收支持。

## 阶段说明

| 阶段 | 输入 | 输出 | 质量要求 |
| --- | --- | --- | --- |
| 需求评审 | 需求文档 | 测试疑问、风险 | P0/P1 需求清楚 |
| 测试方案 | 需求、设计 | `TEST_PLAN.md` | 范围、策略、环境明确 |
| 用例编写 | 测试方案 | `TEST_CASES.md` | 可执行、可判断、可追踪 |
| 用例评审 | 测试用例 | 评审结论 | 覆盖核心风险 |
| 测试执行 | 用例、环境 | 执行结果 | 证据完整 |
| 测试报告 | 执行结果、缺陷 | `TEST_REPORT.md` | 结论清晰 |
