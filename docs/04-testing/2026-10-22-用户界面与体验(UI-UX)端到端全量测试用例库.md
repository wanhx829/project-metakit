# 用户界面与体验 (UI/UX) 端到端全景功能测试用例库

**文档版本**：v1.0.0  
**核心理念**：**以用户视角为第一公民**。用户不关心后台技术架构，核心关心界面能否正常打开、视觉元素是否完整、操作是否有直观反馈、核心业务是否一键闭环。  
**覆盖系统**：
1. **自动化运维传输工具前端** (`http://127.0.0.1:8880`)
2. **现场运维控制台前端** (`http://10.44.3.194:18880`)
3. **微服务基础平台门户前端** (`http://10.44.3.194:30010`)  
**最后更新**：2026-10-22

---

## 1. 用户体验与界面质量四维评估模型 (UX Dimension)

所有前端功能测试用例均基于以下四维标准设计：

| 评估维度 | 核心用户诉求 | 质量门禁与断言标准 |
| :--- | :--- | :--- |
| **1. 页面加载与可用性 (Availability)** | 打开即用，杜绝白屏与资源报错 | 首屏渲染时间 $\le 2s$；HTTP 状态码 200；控制台 0 未捕获异常 (Uncaught Error)。 |
| **2. 操作交互与即时反馈 (Responsiveness)** | 点击有感知，状态明确 | 按钮点击触发 Loading 态；异步操作完成后提供 Toast 提示；耗时任务具备进度条。 |
| **3. 防误触与安全性 (Safety & Guards)** | 危险操作有兜底，表单防错 | 密码输入掩码；敏感删除/重启操作必须弹出确认 Modal；必填项校验有红色 Tooltip。 |
| **4. 状态同步与视觉直观 (Visual Consistency)** | 所见即所得，状态真实 | 后台服务变动后前端自动/轮询更新状态（绿灯/红灯）；布局在 1920×1080 与 1280×720 下无挤压错位。 |

## 2. 自动化运维传输工具 (Implement Client) 页面用例

### UI-TRANS-001: 硬件 MAC 识别与未授权安全蒙层提示
- **页面入口**：`http://127.0.0.1:8880/#/`
- **用户旅程**：未激活客户端初次打开传输工具。
- **界面预期**：
  1. 页面正中弹出全屏/半透明锁定蒙层；
  2. 明确展示本机物理网卡 MAC 地址，并提供“一键复制”快捷按钮；
  3. 提示文案“当前设备未授权，请将机器码提供给管理员获取离线激活授权码”；
  4. 背景其他操作卡片被禁用，无法穿透点击。

### UI-TRANS-002: 项目卡片检索、分类分页与状态角标
- **页面入口**：`http://127.0.0.1:8880/#/project`
- **用户旅程**：已授权用户查看项目列表并搜索。
- **界面预期**：
  1. 顶部提供项目搜索框、平台筛选下拉菜单（ARM / X86）；
  2. 项目卡片网格布局，卡片内清晰展示：项目名称、项目ID（如 `523`）、当前部署状态（`未部署`、`已部署`、`待更新`）；
  3. 点击搜索后，列表在 500ms 内局部重绘，无全页刷新闪烁。

### UI-TRANS-003: 初次部署包断点下载与进度动画反馈
- **页面入口**：`http://127.0.0.1:8880/#/project/detail?id=523`
- **用户旅程**：点击“下载初次部署包”。
- **界面预期**：
  1. 按钮变为不可点击并附带 Loading Spinner；
  2. 弹出下载任务进度条，动态显示传输速度（如 `12.5 MB/s`）、已下载/总大小（如 `1.8 GB / 2.9 GB`）与百分比；
  3. 网络抖动或意外暂停后，再次点击支持“断点续传”，进度不从 0 开始。

### UI-TRANS-004: 一键部署安装控制台表单与 IP 校验
- **页面入口**：`http://127.0.0.1:8880/#/deploy/init`
- **用户旅程**：推送部署介质至现场目标机。
- **界面预期**：
  1. 弹出结构化表单：目标机 IP、SSH 端口、用户名、密码；
  2. 格式校验：若输入非法 IP（如 `999.999.1.1`），输入框下立即高亮红色提示“请输入正确的 IPv4 地址”；
  3. 确认推送后，页面切换至步进器（Steps），当前执行步骤（如“正在解压底座资源包”）高亮闪烁。

## 3. 现场运维控制台 (Deployment Console) 页面用例

### UI-CONSOLE-001: 现场环境初始化步进引导流 (Wizard)
- **页面入口**：`http://10.44.3.194:18880/#/init`
- **用户旅程**：运维人员首次登录控制台进行现场引导配置。
- **界面预期**：
  1. 顶部横向展示三步引导进度条：`Step 1: 基础配置` $\rightarrow$ `Step 2: 主机与存储` $\rightarrow$ `Step 3: 启动初始化`；
  2. 主机配置表格支持动态增删行（添加 Worker 节点）；
  3. 点击“开始初始化”弹出二次确认提示，初始化过程中实时输出日志流窗口，支持自动向下滚动（Auto-scroll）。

### UI-CONSOLE-002: 服务管理全景表格与平滑启停交互
- **页面入口**：`http://10.44.3.194:18880/#/service`
- **用户旅程**：运维人员查看微服务运行状况并执行重启。
- **界面预期**：
  1. 列表展示全部服务卡片：服务标识、当前运行版本（如 `2.2.5.30-frontend-2`）、副本数（`1/1`）、健康状态（绿点 `正常运行` / 红点 `异常`）；
  2. 每行提供快捷操作按钮：`重启`、`版本升级`、`查看日志`；
  3. 点击“重启”按钮，弹出确认框；确认后状态标签变为黄色 `重启中...`，Pod 就绪后自动恢复绿色 `正常运行`，界面不发生整页强制跳转。

### UI-CONSOLE-003: Flyway 数据库升级日志抽屉 (Drawer)
- **页面入口**：`http://10.44.3.194:18880/#/service` -> 点击升级详情
- **用户旅程**：模块升级时查看数据库脚本执行情况。
- **界面预期**：
  1. 从屏幕右侧滑出日志抽屉，背景半透明遮罩；
  2. 抽屉内清晰显示执行版本列表：`V1.0__init.sql (成功)`、`V2.0__add_column.sql (成功)`；
  3. 若某脚本执行失败，该行以红色高亮并显示具体错误信息，支持点击“复制日志”或“重试”。

### UI-CONSOLE-004: 9 大核心工业中间件拓扑看板
- **页面入口**：`http://10.44.3.194:18880/#/middleware`
- **用户旅程**：日常巡检工业中间件集群健康度。
- **界面预期**：
  1. 仪表盘卡片网格：MySQL、Redis 集群、RabbitMQ、Nacos、MinIO、InfluxDB 等；
  2. 每个卡片清晰呈现：实例数、监听端口、CPU/内存实时使用率；
  3. 异常预警：当中间件服务宕机时，对应卡片变为醒目红色警报样式，并置顶显示。

## 4. 微服务基础平台门户 (Web Portal) 页面用例

### UI-PORTAL-001: 统一门户登录页面视觉与交互
- **页面入口**：`http://10.44.3.194:30010/login.html#/login`
- **用户旅程**：用户进入业务系统首屏。
- **界面预期**：
  1. 页面居中呈现工业化企业登录面板，包含品牌 Logo、系统标题；
  2. 输入框包含占位符（Placeholder），密码输入框默认掩码显示并提供“小眼睛”明暗文切换图标；
  3. “记住密码”复选框点击可正常勾选；
  4. 当输入空账号点击“登录”时，前端直接拦截并提示“请输入用户名”，不发送无意义网络请求。

### UI-PORTAL-002: 错误凭据友好提示与防暴力重试
- **页面入口**：`http://10.44.3.194:30010/login.html#/login`
- **用户旅程**：用户输入了错误的用户名或密码。
- **界面预期**：
  1. 点击登录后，按钮显示短暂 Loading 状态；
  2. 页面顶部或右上方滑出 Element-UI 红色 Message 提示“用户名或密码错误”；
  3. 密码输入框自动清空并聚焦，页面无崩溃或白屏；
  4. 连续错误达到阈值时展示验证码输入框。

### UI-PORTAL-003: 登录成功后门户主框架 (Layout) 渲染与菜单权限
- **页面入口**：`http://10.44.3.194:30010/#/dashboard`
- **用户旅程**：使用有效管理员凭据登录成功。
- **界面预期**：
  1. 页面平滑重定向至业务中台主页；
  2. 顶部导航栏展示当前租户、登录用户名、全屏切换按钮、个人中心下拉菜单；
  3. 左侧侧边栏自动根据该用户权限动态渲染菜单树（组织架构、用户管理、系统监控、权限配置）；
  4. 点击折叠/展开侧边栏，主内容区自适应伸缩，无布局抖动。

### UI-PORTAL-004: 用户与组织权限树交互体验
- **页面入口**：`http://10.44.3.194:30010/#/system/user`
- **用户旅程**：业务管理员管理组织机构与员工账号。
- **界面预期**：
  1. 左侧树形展示部门组织架构，支持节点点击筛选、折叠与展开；
  2. 右侧表格展示该部门下的用户清单（工号、姓名、角色、状态开关）；
  3. 表格支持行操作（编辑、重置密码、禁用），点击“编辑”在页面中央弹出 Dialog 模态框，模态框支持 ESC 退出与遮罩点击关闭。

## 5. 自动化 UI 测试驱动与执行规约

在驾驶舱通用框架中，前端用例通过内嵌的无头浏览器引擎进行自动化回归驱动：

```bash
# 1. 打开指定页面
agent-browser open "http://10.44.3.194:30010/login.html#/login"

# 2. 检查 DOM 交互元素就绪
agent-browser snapshot -i

# 3. 模拟用户输入表单
agent-browser fill @e4 "admin" && agent-browser fill @e5 "wrong_password"

# 4. 模拟点击提交按钮
agent-browser click @e3

# 5. 断言操作反馈并截图存证
agent-browser screenshot assets/test_feedback.png
```
