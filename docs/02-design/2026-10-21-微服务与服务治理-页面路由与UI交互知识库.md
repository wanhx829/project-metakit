## 2. 核心功能页面 UI 元素与交互元数据（供 Browser Agent 交互录制）

### 2.1 页面一：优雅发布与重启控制台 (`/governance/graceful`)

#### UI 结构特征与选择器 (Selectors)
- **集群与命名空间选择器**：`select[name="clusterName"]`, `select[name="namespace"]`
- **服务列表表格**：`table.service-graceful-table`
  - 每一行包含：服务名称、副本数 (Ready/Desired)、Nacos 状态 (UP/OUT_OF_SERVICE)、当前 Pod 列表。
- **操作按钮**：
  - 优雅重启按钮：`button[data-action="graceful-restart"]`
  - 优雅下线按钮：`button[data-action="graceful-offline"]`
- **滚动进度状态弹窗**：`div.rollout-status-modal`
  - 进度指示条：`.progress-bar`
  - 阶段日志：`.rollout-log-terminal`

#### 交互行为时序（Browser Recording Flow）
1. 浏览器打开 `/governance/graceful`；
2. 在下拉框选择目标集群（如 `test-cluster`）与命名空间（如 `autoops-test`）；
3. 表格加载展示目标服务，如 `syncplant-business-eam`；
4. 点击行末 `[优雅重启]` 按钮，系统弹出确认对话框；
5. 点击二次确认 `[确定]`，系统发起 `POST /api/k8s/deployment/graceful-restart`；
6. 弹窗自动轮询展示 `GET /api/k8s/deployment/rollout-status`，逐步显示：
   - `[Phase 1] 流量摘除中 (Nacos deregistering...)`
   - `[Phase 2] 等待在途请求归零 (Draining in-flight requests...)`
   - `[Phase 3] 新 Pod 启动与反向预热 (Warming up...)`
   - `[Phase 4] 滚动完成 (Ready 1/1)`
7. 点击 `[完成]` 关闭弹窗，表格刷新状态为正常。

### 2.2 页面二：API 管控中心 (`/governance/api-control`)

#### UI 结构特征与选择器 (Selectors)
- **左侧模块功能树**：`div.module-tree`
  - 树节点：`.tree-node[data-module-id="xxx"]`
- **顶部检索表单**：
  - 路由搜索框：`input[placeholder="请输入接口路径，如 /api/order/create"]`
  - 请求方法过滤：`select[name="httpMethod"]` (GET / POST / PUT / DELETE)
- **API 列表表格**：`table.api-control-table`
  - 路径列：`.col-route`
  - 状态开关：`input.switch-monitor[type="checkbox"]`
  - 实时 QPS 列：`.col-qps`
  - P99 耗时列：`.col-p99`
  - 操作列按钮：`button.btn-trend` (趋势), `button.btn-limit` (限流)
- **限流配置模态框**：`div.limit-modal`
  - 阈值类型单选：`input[name="thresholdType"][value="QPS"]`
  - 单服务 QPS 输入框：`input[name="qpsCount"]`
  - 统计窗口：`input[name="windowIntervalSec"]`
  - 保存并下发按钮：`button.btn-save-publish`

#### 交互行为时序（Browser Recording Flow）
1. 浏览器打开 `/governance/api-control`；
2. 点击左侧功能树中的“订单服务模块”；
3. 右侧表格自动加载该模块下注册的 15 个 API 路由；
4. 找到 `/api/order/create`，勾选其“开启监控”开关，触发 `POST /apiControl/monitorStatus`；
5. 点击该接口行末的 `[配置限流]` 按钮，弹出限流模态框；
6. 模态框自动填入 API 路径 `/api/order/create`；
7. 填写 QPS 阈值为 `1000`，流控效果选择“快速失败”；
8. 点击 `[保存并下发]`，前端向后台提交请求并收到 200 返回；
9. 列表对应项显示绿色“限流已生效”徽章。
