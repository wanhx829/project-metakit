# 运维控制台 - 全量 API 契约与数据字典

**基准路径**：`http://<host>:18880`  
**认证机制**：Cookie-based Session (`deployment_session`)  
**数据格式**：`application/json; charset=utf-8`  
**最后梳理**：2026-10-22

---

## 1. 核心数据结构与统一返回规范

控制台所有 HTTP API 返回体均采用标准 JSON 封装：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

- `code == 200`：请求成功；
- `code != 200`：业务或系统错误，`msg` 包含详细错误提示信息。

## 2. API 接口功能域分类与契约清单 (188 个接口映射)

| 功能域分类 | 常见路径前缀 | 核心能力说明 | 代表性接口示例 |
| :--- | :--- | :--- | :--- |
| **1. 鉴权与系统会话** | `/user/*` | 管理员登录、密码重置、Token 校验、退出登录 | `POST /user/login`<br>`GET /user/info`<br>`POST /user/logout` |
| **2. 环境初始化与状态** | `/status/*`<br>`/project/*` | 获取底层底座部署进度、项目元数据、初始化配置 | `GET /status/initStatus`<br>`POST /project/saveProjectConfig`<br>`POST /project/initEnvironment` |
| **3. 主机与节点管理** | `/host/*`<br>`/node/*` | 纳管宿主机节点、网卡绑定、硬件资源规格获取 | `GET /host/list`<br>`POST /host/add`<br>`GET /node/resourceInfo` |
| **4. 微服务生命周期** | `/service/*`<br>`/module/*` | 模块离线解包、镜像推送、Flyway 升级编排、上线 | `POST /service/serviceOnline`<br>`GET /service/list`<br>`POST /service/restart`<br>`POST /service/uninstall` |
| **5. 中间件治理** | `/middleware/*` | 9 大中间件的启停、重启、配置下发、状态探针 | `GET /middleware/status`<br>`POST /middleware/restart`<br>`POST /middleware/updateConfig` |
| **6. K8s 云原生底座** | `/k8s/*` | 容器组 Pod 查看、Service 映射、ConfigMap 管理 | `GET /k8s/pods`<br>`GET /k8s/services`<br>`POST /k8s/restartPod` |
| **7. 动态网关与微服务路由** | `/gateway/*`<br>`/route/*` | 统一网关动态路由配置、权重分配、协议转发 | `GET /gateway/routes`<br>`POST /gateway/syncRoute` |
| **8. 限流与熔断降级** | `/sentinel/*`<br>`/limit/*` | 规则查询、流控阈值设定、降级策略热同步 | `GET /sentinel/rules`<br>`POST /sentinel/saveRule` |
| **9. 监控告警与指标** | `/monitor/*`<br>`/metric/*` | 主机指标（CPU/MEM/IO/NET）、服务探针、告警事件 | `GET /monitor/systemMetrics`<br>`GET /monitor/alerts` |
| **10. 备份与容灾恢复** | `/backup/*`<br>`/restore/*` | SQLite 元数据备份、MySQL 库备份、离线还原 | `POST /backup/create`<br>`GET /backup/list`<br>`POST /backup/restore` |
| **11. 审计与系统日志** | `/log/*`<br>`/audit/*` | 部署日志流水、组件运行日志查询、审计轨迹 | `GET /log/deployLogs`<br>`GET /log/auditRecords` |
| **12. 离线升级与补丁** | `/upgrade/*` | 控制台自身二进制离线热更、系统级补丁安装 | `POST /upgrade/checkPackage`<br>`POST /upgrade/apply` |

## 3. 核心领域数据模型 (SQLite 表结构定义)

在控制台数据存储 `/deployment/deploy/deployment_data.db` 中包含以下核心实体：

### 3.1 项目元数据表 (`t_project_info`)
- `id`: 主键 ID；
- `project_code`: 项目编码（如 `sciyon_mes`）；
- `project_name`: 项目中文名称；
- `deploy_status`: 部署状态（0: 待初始化, 1: 部署中, 2: 部署完成）；
- `created_at` / `updated_at`: 时间戳。

### 3.2 节点与主机表 (`t_host_node`)
- `id`: 节点 ID；
- `ip_address`: 节点内网 IP；
- `ssh_port`: SSH 端口（默认 22）；
- `role`: 节点角色（`master` / `worker` / `standalone`）；
- `cpu_cores`: CPU 逻辑核数；
- `memory_mb`: 内存总量；
- `disk_gb`: 磁盘容量。

### 3.3 模块与服务表 (`t_service_instance`)
- `service_id`: 服务唯一标识（如 `sciyon-web`, `sciyon-gateway`）；
- `service_name`: 服务显示名称；
- `version`: 当前部署版本（如 `2.2.5.30-frontend-2`）；
- `image_url`: 镜像仓库路径（如 `10.44.3.194:30500/sciyon/web:2.2.5.30`）；
- `replicas`: 运行副本数；
- `status`: 运行状态（`RUNNING`, `STARTING`, `STOPPED`, `FAILED`）。
