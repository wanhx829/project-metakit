# Prompt Engineering

本文件定义项目内提示词的编写和维护规则。

## 提示词分层

| 类型 | 位置 | 用途 |
| --- | --- | --- |
| 项目规则 | `AGENTS.md` | 所有 AI 任务的入口规则 |
| AI 上下文 | `docs/09-ai-context/` | 项目事实、读取顺序、工作流 |
| 阶段技能 | `skills/` | 生命周期阶段方法 |
| 任务提示词 | `prompts/` | 启动具体 AI 任务 |

## 编写原则

1. 目标明确：提示词必须说明要产出什么。
2. 输入明确：说明需要读取哪些文档或文件。
3. 输出稳定：使用固定标题、表格或字段。
4. 约束清楚：说明禁止虚构、禁止越界、如何处理缺失信息。
5. 可落地：输出应能写回项目文档、源码或测试。

## 推荐结构

```markdown
# 提示词名称

## 任务目标

## 输入

## 输出结构

## 执行规则

## 质量检查
```

## 维护规则

- 提示词不要塞入大量项目事实，事实应放在 `docs/`。
- 提示词不要和技能重复，技能写方法，提示词写任务启动方式。
- 如果提示词输出结构变化，应同步更新引用它的文档。
- 临时提示词不应进入本目录，除非已经能复用。
