# EmpoworX 自动化运维平台 V3.0 - 项目概览 (Project Overview)

## 项目名称

**EmpoworX 自动化运维平台 V3.0 升级项目**

## 项目背景

面向企业与工业互联网复杂的微服务、容器集群及多数据中心混合环境，提供从底层操作系统适配、虚拟化管理、CI/CD 制品打包、官方中间件运维，到运行期微服务治理（优雅上下线、API 管控、限流熔断、灰度发布）以及应用一键编排发布的全生命周期自动化运维平台。

## 项目目标

1. 搭建标准化、AI 能够全链路理解的 5 大业务产品知识库与端到端场景链。
2. 消除系统发布抖动（实现 0 丢包优雅上下线与预热）。
3. 盘点与纳管全集群 API 资产，提供实时性能画像与 Sentinel 精准流控。
4. 规范测试项、自动化验收用例与运维配置排障规范。

## 代码工程架构边界 (只读代码)

- `src/empoworx-kubea`：Kubernetes 集群资源调度、优雅发布探针、虚拟机监控、OOM Dump 处理引擎。
- `src/syncplant-auto-deployment`：自动化部署调度中心、模板渲染、WebSocket 执行通知、Flyway 脚本编排。
- `src/empoworx-devops-cloud`：DevOps 业务云管控制台、项目/模块/环境定义、Nacos 配置下发、CI/CD 打包流水线调度。
- `src/kubernetes-manifests`：Kubernetes 标准资源清单与 Helm 编排模板。
