# 运维控制台 (Deployment Console) 产品说明书

**文档版本**：v1.0.0  
**适用范围**：现场目标宿主机部署与运维治理  
**主要受众**：现场运维工程师、测试工程师、AI 辅助研发代理  
**最后更新**：2026-10-22

---

## 1. 产品定位与目标

运维控制台（`syncplant-auto-deployment`）是部署于工业互联网现场物理机/宿主机（单机或集群）的核心管控系统。其目标是为现场隔离环境提供**全自动化底座拉起、离线微服务全生命周期管理、工业中间件高可用托管、配置与数据库迁移编排以及环境灾备治理**。

---

## 2. 核心用户与典型使用场景

1. **现场初次交付**：
   - 运维工程师通过传输工具将云端初次部署包推送至目标机；
   - 运维控制台通过引导式界面，一键初始化底层 K8s 容器运行时、Cilium eBPF 网络插件、本地存储类，并自动化拉起 9 大核心工业中间件。
2. **微服务与业务模块敏捷迭代**：
   - 接收增量模块包，执行自动镜像导入（Local Registry `:30500`）；
   - 执行 Flyway 数据库表结构变更升级与回滚；
   - 自动生成/更新 K8s Deployment 与 Service 配置，并挂载至微服务网关。
3. **日常运维监控与故障自愈**：
   - 监控宿主机 CPU、内存、磁盘及各微服务 Pod 健康度；
   - 提供中间件动态参数热更新、服务重启、限流降级及容灾备份导出/恢复。

---

## 3. 功能特性与业务需求规格

### 3.1 环境初始化与引导 (Initialization & Bootstrap)
- **FR-DC-01**：支持初次部署包自动解压与完整性校验。
- **FR-DC-02**：底座环境一键拉起：包括 Docker、K8s（v1.35.5）、Cilium（v1.19.4）、OpenEBS 本地存储。
- **FR-DC-03**：9 大中间件单节点/集群拓扑自动化编排：MySQL 8.0、Redis Cluster（6 节点）、RabbitMQ、Nacos、MinIO、InfluxDB、MongoDB、Elasticsearch、VictoriaMetrics/Prometheus。
- **FR-DC-04**：初始化进度状态机流转控制：未部署 (`0`) -> 部署包已解包 (`1`) -> 底座与中间件就绪 (`2`)。

### 3.2 模块管理与上线 (Module Deployment & Upgrade)
- **FR-DC-05**：增量模块上传与解析：解析模块包内 `manifest.json`、Docker 镜像包与 Flyway SQL 目录。
- **FR-DC-06**：镜像分发：自动推送模块镜像至宿主机私有仓库 `10.44.3.194:30500`。
- **FR-DC-07**：Flyway 数据表自动化迁移：支持版本顺序执行与失败中断保护。
- **FR-DC-08**：服务编排与发布：通过 Kubernetes API 创建或更新 Pod、Deployment，注入环境变量与 ConfigMap。

### 3.3 中间件治理与监控 (Middleware Management)
- **FR-DC-09**：各中间件运行实例进程/Pod 状态、资源占用（CPU/内存）、网络端口实时感知。
- **FR-DC-10**：支持中间件服务启动、停止、重启与动态配置更新。
- **FR-DC-11**：支持数据库连接池探针与性能指标查看。

### 3.4 微服务治理与限流熔断 (Governance & Circuit Breaking)
- **FR-DC-12**：动态接入微服务网关（Spring Cloud Gateway / Sentinel 规则下发）。
- **FR-DC-13**：QPS 阈值配置、慢调用比例降级、异常比例降级规则热下发。

### 3.5 备份与容灾恢复 (Backup & Disaster Recovery)
- **FR-DC-14**：支持控制台元数据 SQLite 数据库定时与手动备份。
- **FR-DC-15**：支持 MySQL 业务库全量导出与一键还原。
- **FR-DC-16**：支持微服务配置文件与 Nacos 配置集快照打包导出。

---

## 4. 非功能性需求 (NFR)

- **离线运行能力**：控制台及其所管理的所有组件必须能在 100% 断绝公网的环境下正常运行，所有镜像与依赖包均为本地化离线制品。
- **高韧性自愈**：控制台 Go 程序崩溃后，由 Systemd 服务自动拉起，且不影响宿主机上已运行的容器与微服务业务。
- **安全性与鉴权**：接口遵循 RBAC 鉴权机制，敏感操作（密码重置、数据恢复、节点销毁）需双重确认并留存审计日志。
