# 自动化装机与底层部署脚本体系产品说明书

**文档版本**：v1.0.0  
**适用范围**：物理机/虚拟机自动化 PXE 裸机安装与底座环境部署脚本体系  
**最后更新**：2026-10-22

---

## 1. 产品定位与目标

自动化装机与底座脚本体系是整个交付链条的基石（L0 ~ L1 层）。它将繁琐、容易出错的人工装机、网络配置、内核调优、存储划分与容器底座拉起，固化为标准化、无人值守的自动化流程，确保所有现场环境的基础设施达到 100% 幂等一致。

---

## 2. 核心架构与功能规格

### 2.1 PXE 自动化网络装机 (OS Bootstrap)
- **门禁机制 (IP Reachability Preflight)**：
  - 在发起装机前，必须执行 ICMP Ping 探测；
  - **强制门禁规则**：目标 IP 必须 100% 不可达（Ping 不通），证明该 IP 未被局域网存量设备占用且待装机主机处于离线待就绪状态；
  - 装机必须经过人工二次确认（Human Review）后方可触发。
- **无人值守安装 (Kickstart Automation)**：
  - 自动向 PXE TFTP/DHCP 注入针对目标 MAC 的启动配置文件；
  - 自动挂载 Rocky Linux 10.1 / CentOS 镜像；
  - 自动化磁盘分区配置（LVM 根分区、数据盘挂载 `/deployment`）；
  - 注入安全口令基线、SSH 公钥及初始化网卡配置。

### 2.2 宿主机底座基线脚本 (Host Baseline)
- **内核与系统调优**：
  - 关闭 SELinux、禁用 Swap 分区；
  - 调大系统文件句柄数 `fs.file-max`、进程数上限 `kernel.pid_max`；
  - 优化网络转发参数：`net.ipv4.ip_forward = 1`，`net.bridge.bridge-nf-call-iptables = 1`。
- **存储与目录规划**：
  - 核心应用与数据目录统一规整于 `/deployment`；
  - Docker 数据根目录设为 `/deployment/docker-data`；
  - 日志与备份目录分级。

### 2.3 底座拉起脚本 (`install.sh` & `start.sh`)
- **离线依赖解压**：解包初次部署包中的 RPM 依赖包、容器镜像 Tar 包；
- **容器与网络底座**：
  - 启动 Docker 守护进程与本地私有仓库 Docker Registry（`:30500`）；
  - 部署 Kubernetes 单节点或集群控制面；
  - 安装 Cilium eBPF 网络插件，替换传统 kube-proxy；
- **控制台托管**：
  - 注册 `syncplant-auto-deployment` 为 Systemd 服务守护进程；
  - 监听 `:18880` 端口并完成自检。

---

## 3. 验收标准与测试基准

1. **装机门禁标准**：Ping 探测不通才放行装机，装机完成后 SSH 22 端口必须在规定超时时间内可连通；
2. **幂等性标准**：`install.sh` 重复执行必须具备重入保护，不得覆盖或损坏已写入的业务数据；
3. **底座就绪标准**：K8s 节点处于 `Ready` 状态，Cilium Pod 运行正常，Local Registry 可以正常进行 `docker push` 与 `docker pull`。
