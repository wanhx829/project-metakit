# 项目产品驾驶舱通用框架 (Product Cockpit Framework)

## 1. 概念模型与定位

项目产品驾驶舱（Product Cockpit Framework）是一个**业务数据驱动的自主交付与验证框架**。它将通用的 AI 认知执行能力与具体的产品业务知识解耦，形成类似“操作系统内核与应用程序数据包”的关系：

- **驾驶舱内核 (Cockpit Core)**：提供通用能力，包括自然语言意图分发、测试用例自适应编排、多协议工具执行（SSH/MCP/HTTP/Playwright）与验证闭环。
- **业务数据包 (Cockpit Pack)**：特定产品的专属知识库与资产定义，实现“换数据包即换驾驶舱”。

## 2. 驾驶舱模式流转机制

```
          [人类领航员 (User)]
                  │ 1. 给出业务输入 / 指导探索目标
                  ▼
       ┌─────────────────────────┐
       │   驾驶舱通用内核引擎     │
       │   (Cockpit Core Engine) │
       └────────────┬────────────┘
                    │ 2. 动态挂载对应数据包
                    ▼
     ┌──────────────────────────────┐
     │ cockpit/packs/<product-id>/  │
     │ ├── pack.json                │ 3. 业务数据驱动
     │ ├── 01-requirements/ (PRD)   │
     │ ├── 02-design/ (API/架构)    │
     │ ├── 04-testing/ (测试用例库)  │
     │ └── 07-operations/ (配置/密码)│
     └──────────────┬───────────────┘
                    │ 4. 驱动工具执行与验证
                    ▼
          [真实环境 (Dev/Ops/Test)]
```

## 3. 当前支持的产品驾驶舱清单

| 驾驶舱名称 | 标识符 | 核心覆盖场景 | 对应数据包目录 |
| :--- | :--- | :--- | :--- |
| **运维平台项目产品驾驶舱** | `cockpit-pack-ops-platform` | 裸机PXE装机、网闸断点传输、运维控制台初始化、中间件拉起、服务全生命周期上线 | `cockpit/packs/ops-platform/` |
| **微服务基础平台驾驶舱** | `cockpit-pack-microservices-base` | 微服务网关路由、OAuth2 鉴权中心、用户组织权限、系统资源调度、前端门户交互 | `cockpit/packs/microservices-base/` |
| **自定义业务驾驶舱 (待接入)** | `<product-slug>` | MES 制造执行、SCADA 数据采集、ERP 业务等 | `cockpit/packs/<product-slug>/` |

## 4. 人机协同操作范式

1. **领航探索新产品**：
   - 方式：用户指定新产品目录或提出探索目标（如：“现在我们来探索微服务基础平台”）；
   - 驾驶舱：挂载对应数据包，主动探测接口、解析数据模型、填充测试用例库，呈报用户审核。
2. **业务数据驱动执行**：
   - 用户指令：“测下部署微服务测试平台” $\rightarrow$ 运维平台驾驶舱调用云端打包、传输工具、控制台上线流程；
   - 用户指令：“回归测试用户与角色赋权链路” $\rightarrow$ 微服务基础平台驾驶舱调用 OAuth2 凭据、网关鉴权 API、数据库断言验证；
   - 用户指令：“装机一个测试环境” $\rightarrow$ 运维平台驾驶舱触发 IP Ping 连通性门禁并调用 PXE 自动化安装。
